Farmnote is a geo based note taking web-app.

# Projects
Each project has an `AGENTS.md`
* `/backend`: FastAPI backend
* `/frontend`: Angular frontend

# Agent docs
Write a summary of your implementation into `agent_docs`.
Add a short reference in `agent_docs/index.md` (file, short description).
Before you start implementing, read `agent_docs/index.md` to load the right information into your context

# Commit Conventions
Use default Git commit messages

# Skills
in the `skills` folder:
* `generate-api-client`: Generates the OpenAPI client for the frontend
